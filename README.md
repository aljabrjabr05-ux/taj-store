# الجابر للمحاسبة

نظام محاسبة ومخزون عربي RTL بصيغة PWA.

## الوظائف الحالية
- فواتير بيع وشراء.
- ربط الفواتير بالمخزون.
- حركات وارد وصادر.
- أصناف وزيادة/نقصان الكمية عبر الفواتير.
- عملاء ودفتر ديون.
- إدخال ملاحظات الديون بالصوت عبر Web Speech API عند دعم المتصفح.
- تقارير أساسية.
- طباعة فاتورة بشكل ورقة فاتورة.
- مشاركة الفاتورة من الهاتف عبر Web Share، ومع عدم توفره يفتح WhatsApp برسالة منظمة.
- قابل للتثبيت كتطبيق PWA.

## تشغيل سريع
يمكن استضافة الملفات على GitHub Pages أو أي استضافة HTTPS.

> هذه النسخة تستخدم LocalStorage للتخزين المحلي. للاستخدام المحاسبي متعدد الأجهزة والإنتاج يلزم ربطها بقاعدة بيانات وواجهة API ومصادقة ونسخ احتياطي.

## تثبيت داخل مستودعك
بعد فك الضغط:
```bash
git clone https://github.com/aljabrjabr05-ux/taj-store.git
cd taj-store
# انسخ محتويات aljabr-accounting إلى جذر المشروع
git add .
git commit -m "Build Aljabr Accounting PWA"
git push origin main
```

أو ارفع الملفات من واجهة GitHub.

## الهاتف
افتح الموقع من Chrome/Edge على Android، ثم اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
